# Manus Experimental Prototypes

This directory contains source exported from experimental workflow work. It is intentionally isolated from final application architecture so the production team can adopt, replace, or discard it without merging into a mainline product path.

The current `field-ledger/` prototype is a client-only workflow demonstrator. Its full migration boundary, limitations, and asset replacement steps are documented in [`../../docs/manus-prototype-notes.md`](../../docs/manus-prototype-notes.md).
